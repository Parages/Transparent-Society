# 项目文件夹说明

- 1、1.1、1.2 都属于项目 1，统一存放在 projects/01/
- 2、2.1 统一存放在 projects/02/
- 3 统一存放在 projects/03/
- 4、4.1 统一存放在 projects/04/
- 12、12.1 统一存放在 projects/12/
- 23、23.1 统一存放在 projects/23/

每个项目文件夹结构：
- projects/01/
  - index.html
  - assets/
    - posters/
    - photos/

使用方式：
- 把该项目的海报图直接拖进 assets/posters/
- 把相关照片拖进 assets/photos/
- 修改 index.html 里的介绍文字即可
